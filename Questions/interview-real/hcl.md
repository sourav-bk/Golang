"Given two integer arrays nums1 and nums2 where nums1 is a subset of nums2, find the 'Next Greater Element' for each element in nums1.
The next greater element of a number x in nums2 is the first greater element to its right. If it does not exist, return -1. The output should be an array of the same length as nums1 containing these values.
Example:
Input: nums1 = [4, 1, 2], nums2 = [1, 3, 4, 3]
Output: [-1, 3, -1]
Can you solve this in O(N + M) time complexity?"


Merge Overlapping Intervals(Ex: [{1,3}, {2,6}, {8,10}, {15,18}] → [{1,6}, {8,10}, {15,18}])
