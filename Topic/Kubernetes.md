### What Problem Solved K8s ?

1. **Manual Deployment**

   If you had 100 containers, you had to start, stop, and manage them manually.
   
   **K8s Solution:** Automates deployment and management of containers.

2. **Scaling Applications**

   When traffic increased, adding more application instances was difficult.
   
   **K8s Solution:** Automatically scales applications up or down based on demand.

3. **High Availability**

   If a server or container crashed, the application could go down.
   
   **K8s Solution:** Detects failed containers and automatically restarts or replaces them.

4. **Load Balancing**

   Distributing user requests across multiple application instances was complex.
   
   **K8s Solution:** Built-in service discovery and load balancing.

5. **Resource Utilization**

   Servers were often underutilized or overloaded.
   
   **K8s Solution:** Efficiently schedules containers across available nodes.

6. **Environment Consistency**

   Applications worked on a developer's machine but failed in production.
   
   **K8s Solution:** Containers + orchestration provide consistent environments across Dev, Test, and Production.

7. **Rolling Updates and Rollbacks**

   Updating applications could cause downtime.
   
   **K8s Solution:** Supports zero-downtime rolling updates and easy rollbacks.
